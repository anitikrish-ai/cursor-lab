Make custom mouse cursors for Windows.

Draw an arrow, place a character beside it, animate it, and export real .cur and .ani files. It runs in your browser and your files stay on your device.

How it works

  1. Draw an arrow, or import an image to sit beside it.
  2. Click where the pointer should register. That point is the hotspot.
  3. Export a .cur or .ani file, or collect cursors into a pack with an installer.

Help

Make a cursor

  1. In Studio, add an arrow, then import an image to use as a companion beside it.
  2. Use Pick hotspot and click the canvas to set the exact click point.
  3. Choose an effect on a layer and set frames above 1 to animate.
  4. Export .cur for a static cursor or .ani for an animated one. Use Validate to re-read the file.

Install on Windows

Single cursor: right-click the .cur or .ani file and choose Install. Pack: unzip, right-click Install.inf, choose Install, then pick the scheme under Mouse settings, Pointers.

Shortcuts

  • Ctrl+E: download the cursor. Ctrl+S: save the project file
  • Ctrl+wheel on the canvas: zoom
  • Ctrl+K: command menu
  • Ctrl+Z / Ctrl+Y: undo / redo
  • Ctrl+C / Ctrl+V / Ctrl+D: copy / paste / duplicate
  • Drag an image onto the Studio to import it
  • Delete: remove layer. Arrow keys: nudge. Space: play or pause

Format limits

  • Cursors are written with PNG image data, which Windows Vista and later read. Older Windows is not supported.
  • Only PNG-encoded .cur and .ani files can be opened. Opening an .ani keeps its first frame.
  • Animated GIFs import as their first frame.
  • Windows ignores sizes it cannot scale well. 32, 48 and 64 are safest.
